you are agreeing to before you spend an evening on a patch.

## Why this exists

CreaBus Tool is licensed to the public under the
[GNU General Public License v3 or later](LICENSE). Creavision Technology also
sells **CreaBus Tool Pro**, a version that is not under the GPL.

Selling a proprietary version is only lawful if Creavision holds sufficient
rights to *all* the code in it. Contributions belong to the people who wrote
them, so without your permission a contribution could go into the free version
and never into the paid one — which in practice means it could not be merged
at all. This agreement grants that permission, and nothing more than it needs.

## If you would rather not

That is a completely reasonable position, and some people hold it on
principle. Please do not send a pull request in that case — but bug reports,
reproductions, register maps you found in a manual, and "this is wrong and
here is why" are all genuinely valuable and need no agreement at all. Open an
issue instead.

## How you accept

Add a `Signed-off-by` line to each commit, which `git commit -s` does for you:

```
Signed-off-by: Your Name <your.email@example.com>
```

That line means you have read this file and agree to it for that contribution.
Use a real name and a real address — the sign-off is the record that the
agreement was made, and it is worth no more than the identity behind it.

Questions before you start are welcome: open an issue, or write to
<contact@creavisiontechnology.com>.
